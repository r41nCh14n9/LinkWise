## 非功能需求 (NFR)

### NFR-1: 性能需求

| 編碼 | 指標 | 目標 |
|------|------|------|
| NFR-1.1 | 頁面加載時間 | < 2 秒 (首屏), < 3 秒 (全屏) |
| NFR-1.2 | 儀表板數據刷新 | < 1 秒 |
| NFR-1.3 | 搜索結果返回 | < 500ms (1,000 條記錄) |
| NFR-1.4 | API 響應時間 | < 200ms (P99) |
| NFR-1.5 | 並發用戶支持 | 500+ 並發用戶無性能明顯下降 |
| NFR-1.6 | 數據庫查詢 | < 100ms (常用查詢) |

---

### NFR-2: 安全性需求

| 編碼 | 需求 | 說明 |
|------|------|------|
| NFR-2.1 | 身份驗證 | 支持 OAuth 2.0 (Google) 和 OIDC (Keycloak) 及本地帳號 |
| NFR-2.2 | 傳輸加密 | HTTPS 全站 (TLS 1.2+) |
| NFR-2.3 | 密碼存儲 | 本地帳號密碼需加鹽加密 |
| NFR-2.4 | 會話管理 | Token-based 會話，支持自動過期 |
| NFR-2.5 | 數據隔離 | 多租戶企業級隔離，部門級數據權限控制 |
| NFR-2.6 | 敏感數據 | 銀行賬戶、財務信息等需加密存儲 |
| NFR-2.7 | 操作審計 | 所有操作需記錄日誌，可供審計查詢 |
| NFR-2.8 | API 安全 | 支持 API 限流、參數驗證、SQL 注入防護 |
| NFR-2.9 | 文件上傳 | 支持文件類型驗證，防止惡意上傳 |
| NFR-2.10 | 訪問控制 | 基於角色 (RBAC) 的精細化權限控制 |

---

### NFR-3: 合規和審計需求

| 編碼 | 需求 | 說明 |
|------|------|------|
| NFR-3.1 | 操作日誌 | 記錄所有增刪改操作 (操作人、時間、類型、對象、變更內容) |
| NFR-3.2 | 日誌保留 | 最少保留 1 年的完整日誌 |
| NFR-3.3 | 日誌導出 | 管理員可按日期範圍導出操作日誌 |
| NFR-3.4 | 敏感操作告警 | 監控批量刪除、權限修改等異常操作 |
| NFR-3.5 | 用戶登入審計 | 記錄每次登入的時間、IP、設備信息 |
| NFR-3.6 | 數據完整性 | 防止未授權修改，提供完整的變更追蹤 |

---

### NFR-4: 擴展性需求

| 編碼 | 需求 | 說明 |
|------|------|------|
| NFR-4.1 | 模塊獨立性 | 支持各功能模塊獨立升級和擴展 |
| NFR-4.2 | 企業支持 | 支持 1,000+ 家企業同時使用 |
| NFR-4.3 | 異步處理 | 支持後台異步處理耗時操作 |
| NFR-4.4 | 性能優化 | 支持緩存機制減少數據庫壓力 |
| NFR-4.5 | API 版本管理 | 支持多個 API 版本共存，保證向後兼容 |
| NFR-4.6 | 配置管理 | 支持動態調整系統參數無需重啟 |

---

### NFR-5: 可用性需求

| 編碼 | 需求 | 目標 |
|------|------|------|
| NFR-5.1 | 系統可用性 | 99.5% uptime (每月允許最多 3.6 小時宕機) |
| NFR-5.2 | 故障恢復時間 | 15 分鐘內恢復服務 |
| NFR-5.3 | 數據備份 | 每日全量備份，最多丟失 1 小時數據 |
| NFR-5.4 | 異地備份 | 數據備份多份副本存儲在不同地點 |
| NFR-5.5 | 監控告警 | 24/7 系統監控，關鍵指標異常提醒 |
| NFR-5.6 | 自動轉移 | 發生故障時自動轉移至備用系統 |

---

|------|------|------|

## 編碼規則

### 功能需求編碼

格式: `FR-[模塊代碼][序號].[子需求]`

- `FR-D`: Dashboard (儀表板)
  - `D1`: 摘要卡片
  - `D2`: 支出趨勢圖
  - `D3`: 供應商評分
  - `D4`: PR/PO 流程漏斗
  - `D5`: 最近操作清單

- `FR-R`: RBAC (帳號權限)
  - `R1`: 身份驗證
  - `R2`: 用戶管理
  - `R3`: 角色和權限
  - `R4`: 組織結構

- `FR-V`: VMS (供應商管理)
  - `V1`: 供應商檔案
  - `V2`: 風險管理
  - `V3`: 績效追蹤
  - `V4`: Onboarding

- `FR-P`: PR/PO (採購流程)
  - `P1`: PR 創建和管理
  - `P2`: PR 審批
  - `P3`: PO 生成
  - `P4`: PO 狀態和收貨

### 非功能需求編碼

格式: `NFR-[需求類別].[序號]`

- `NFR-1.x`: 性能需求
- `NFR-2.x`: 安全性需求
- `NFR-3.x`: 合規和審計需求
- `NFR-4.x`: 擴展性需求
- `NFR-5.x`: 可用性需求
- `NFR-6.x`: 可維護性需求
